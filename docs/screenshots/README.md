# Screenshots Guide

Drop your app screenshots here with these filenames to have them appear directly in the main `README.md`:

- `feed.png` — Main social feed & stories
- `reels.png` — Vertical video reels player
- `pinboard.png` — Spatial pinboard & library canvas
- `flavors.png` — Material You theme & palette switcher

Recommended screenshot format: 1080×2400 (PNG) from phone or emulator.
